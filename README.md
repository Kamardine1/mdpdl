# MDPDL
## Un gestionnaire de mot de passe simple.
Un compte
---
Défini par :

* Nom du site/application,
* Lien du site,
* Identifiant de connexion,
* 2e identifiant s'il existe,
* Mot de passe,
* La réponse à une question


## Les fonctionnalités :

Copier directement dans le presse-papier :
* le mot de passe voulu

Pouvoir modifier les éléments d'un compte :
* Identifiants
* Mot de passe
* Réponse à une question
* Nom du site/application


Pouvoir :
* Ajouter un compte
* Supprimer un compte


## Les particularités :

Ne jamais afficher un mot de passe, mais avoir un bouton qui copie directement dans le presse-papier.

## L'IHM :
Une UI avec une table contenant les informations de la BDD.
Des boutons en bas de la table pour gérer les données.
