# **MDPDL :**



**Les classes :**
Compte :
---

* nom du site/application
* lien du site
* Identifiant de connexion
* 2e identifiant s'il existe
* mot de passe
* La réponse à une question



## **Les fonctionnalités :**

Copier directement dans le presse-papier :
* le mot de passe voulu OK
* l'identifiant voulu
* le lien d'un site/app
* le nom d'un site/app


Pouvoir modifier les éléments d'un compte : OK
* Identifiants OK
* Mot de passe OK
* Réponse à une question OK
* Nom du site/application OK


Pouvoir :
* ajouter un compte OK
* supprimer un compte OK


## **Les particularités :**

Ne jamais afficher un mot de passe, mais avoir un bouton qui copie directement dans le presse-papier.



## 

## **L'IHM :**

Avoir une colonne qui affiche les noms des applis/ site, avec à coter les colonnes des ID et 2e ID, à coté les boutons pour copier les MDP.
